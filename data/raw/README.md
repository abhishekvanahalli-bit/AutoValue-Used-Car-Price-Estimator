# Raw dataset

Place the training dataset here as:

    data/raw/Car details v3.csv

It is the "Vehicle dataset from CarDekho" published on Kaggle by Nehal Birla:
https://www.kaggle.com/datasets/nehalbirla/vehicle-dataset-from-cardekho

The file the notebook was trained on has 8,128 rows and 13 columns
(name, year, selling_price, km_driven, fuel, seller_type, transmission,
owner, mileage, engine, max_power, torque, seats).

The dataset is not part of the GitHub repository. It is only needed to re-run
the training notebook. The prediction app runs without it.
